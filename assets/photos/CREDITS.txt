Logo (assets/logo.png, assets/logo-white.png, assets/favicon.png) : le vrai logo de l'agence sous
sa nouvelle marque Travels Advisers, fourni le 2026-10-05 (lockup complet couleur, fond
transparent). assets/logo.png est ce lockup recadré serré (emblème "X" + texte "Travels Advisers"
tel que dessiné dans le fichier original), affiché en une seule image dans l'en-tête/pied de page.
assets/logo-white.png est la même image recolorée en blanc (vraie image, pas un filtre CSS, pour
éviter un bug de rendu constaté sur certains navigateurs mobiles) : utilisée par js/script.js sur
l'en-tête transparent au-dessus du hero, et directement dans le HTML pour le logo du pied de page
sur fond sombre. assets/favicon.png est un recadrage de l'emblème seul (le "X"), sur fond
transparent carré pour rester lisible en petit format d'onglet. Remplace le précédent logo Campus
Travel H&K.
